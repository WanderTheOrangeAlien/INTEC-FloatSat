# INTEC-FloatSat
The FloatSat is a project originally developed by the Julius Maximilians University of Würzburg. See the report 
[here](https://www.diva-portal.org/smash/get/diva2:1108195/FULLTEXT02). Its purpose is to be a satellite simulator 
that allows students to experiment with different attitude control algorithms. In 2019, INTEC requested one FloatSat 
sample to the University of Würzburg. Since then, several student teams had experimented with it. This repository 
contains one of those works.

The following project consists of a complete flight control software for the FloatSat. It uses the STM32 HAL and 
its FreeRTOS port.

**(Still a work in progress!)**
