# FloatSat Plotter
This script was done for analyzing data from the FloatSat during the first
phases of the project. It has the following features:

- Live plotting of data
- Can view the datapoints by hovering with the cursor
- Can save the entire timesequence to csv files with Ctrl+S
- Can select a range
- Can save just a range with Shift+Ctrl+S
- Can load files
